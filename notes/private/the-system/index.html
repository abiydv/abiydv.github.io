The System#

This is “The System” to control the chaos on your disk. It’s strictly for working with local files on your system.

Level 1 - Main categories, single digits, 1 to 9 Level 2 - This can either be a sub-category with a double digits prefix 01 to 99, or a simple directory with year prefix Level 3 - Documents, add yearly prefix. Use creation date year prefix if no other year is applicable.

Level 2 and beyond#

Under the main category directory (like 2-Id), you create sub-directories for each sub-category. Determine the name for this sub-directory as follows -

  • First, pick the sub-category name, like India-Investments. Do not use spaces in name, separate words with -.
  • Next, assign it a 2 digit number, 01 onwards. Increment this number by 1 for each new sub-category, like 01-India-Investments.
  • Finally, prefix the category number, like 3.01-India-Investments

Automations#

  1. Utility to notify if document age > 7 days in inbox. Use curl to http post to a ntfy channel.

  2. Utility to auto-tag document with category and sub-category names. Use xattr on MacOS.

Questions#

  1. What happens if you reach 9 in any of the category? Level 1 categories should be broad enough for you to not need more than 5 or 6. If you need more than 9, re-evaluate if any of them share some commonalities, and are perhaps better suited as a Level 2 sub-category which allow upto 99 entries.

  2. I can’t decide where to put a specific document? Add it to 1-System/1.02-Inbox/ directory, sanitise and move to the required directory once you have made up your mind.

  3. Will auto-tagging utility work on both Linux and MacOS? Possibly Yes, when using extended file attributes
